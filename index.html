Sejarah Microsoft

Dari garasi kecil hingga menjadi salah satu perusahaan teknologi terbesar di dunia.

1975

Berdirinya Microsoft

Bill Gates dan Paul Allen mendirikan Microsoft di Albuquerque, New Mexico, untuk mengembangkan interpreter BASIC bagi komputer Altair 8800 (komputer mikro legendaris keluaran tahun 1975).

1980

Kerja Sama dengan IBM (International Business Machines)

Microsoft menandatangani kontrak dengan IBM untuk menyediakan sistem operasi, yang kemudian dikenal sebagai MS-DOS.

1985

Peluncuran Windows 1.0

Microsoft merilis sistem operasi Windows pertama, sebuah lapisan antarmuka grafis di atas MS-DOS.

1990

Windows 3.0

Versi ini menjadi titik balik komersial besar bagi Windows, berkat antarmuka yang lebih baik dan dukungan aplikasi yang lebih luas.

1995

Windows 95 & Internet Explorer

Windows 95 diluncurkan dengan sambutan besar-besaran, memperkenalkan menu Start dan taskbar. Microsoft juga mulai serius menggarap internet.

2001

Windows XP & Xbox

Windows XP menjadi salah satu sistem operasi paling populer sepanjang masa. Di tahun yang sama, Microsoft memasuki industri konsol game lewat Xbox.

2014

Satya Nadella Menjadi CEO

Satya Nadella menggantikan Steve Ballmer sebagai CEO, membawa Microsoft lebih fokus ke komputasi awan (cloud) melalui Microsoft Azure.

2016

Akuisisi LinkedIn

Microsoft mengakuisisi LinkedIn senilai sekitar 26,2 miliar dolar AS, memperluas jangkauannya ke jaringan profesional.

2020-an

Era Kecerdasan Buatan

Microsoft berinvestasi besar pada OpenAI dan mengintegrasikan teknologi AI generatif ke dalam produk-produknya, termasuk Windows, Office, dan Bing melalui Copilot.
